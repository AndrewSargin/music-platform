# Project Overview
This is a music server that allows users to search for songs on different platforms and save them for listening later without ads or download on their device. 
# Goals
#### Main goal
Build a production-like music server.

#### Sub Goals
* Create music server
* Create a client for a server
* Learn basics and practice backend development
* Learn about deployment

# Functional Requirements
* Users can create accounts
* Users can search for music by link to spotify (and Yandex music if possible) or by name
* Users can add music to favorites and other playlists
* Users can download music from the server
* Music streaming
* Playback controls

# Non-Functional Requirements
* CI/CD pipeline
* Backend should have automatic tests
* Not overcomplicate architecture without a reason
* Passwords are stored as hashes
* Error handling, retries on error
* No doubles in database
* Logging 

# Constraints
* AI can be used only to help in studying programming and development, making UI design (not writing it, only prototyping), structuring and reviewing documentation (no writing). No asking to make work for me. This constraint might be changed in future due to my plans but cannot widen the AI's role.
* All documentation must be written in English.
