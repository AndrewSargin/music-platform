While developing this projects I used various tools:
- ERD is made with dbml at [dbdiagram](|https://dbdiagram.io/)
- C4 model was created at [structurizr](https://structurizr.com/)
- OpenAPI is described with [swagger-editor](https://github.com/swagger-api/swagger-editor)
- Docker for containerization
- Goose for db migrations
- sqlc for code generation
